# 13_6-Interpolating-Data
write a script about Census Data
Create a script that will do the following:
• Include the command load census
o This will load two column arrays, cdate (the years of each census) and pop (the
population of the U.S. during each year, in millions)
• Create a graph that plots the following from 1790 to 1990:
o The individual points for the values in the arrays
o A line graph for a cubic spline interpolation of the census data
o A title, axis labels, a grid, and a legend
• Create three output statements that state the approximate population in 1945 using all three
methods of interpolation (linear, cubic spline, and pchip). Round each answer to one decimal
place (in millions).
• Use your cubic spline interpolation to approximate the year when the population reached 100
million. Report that result in an output statement.
